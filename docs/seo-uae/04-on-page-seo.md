# 04 · On-page SEO, page by page (UAE)

## 1. Rules for every page

| Element | Rule |
|---|---|
| **H1 kicker** | The small label above each emotional headline goes **inside** the H1: `<h1><span class="h1-kicker">Shopify agency in Dubai & UAE</span> Your products are great. <em>Your store should sell like it.</em></h1>`. No visual change; the H1 now says what we sell and where. |
| `<title>` | ≤ 60 characters. Keyword + **"Dubai" or "Dubai & UAE"** + benefit/price + `· [Brand]`. Arabic titles ≤ 60 characters too. |
| Meta description | 140–155 characters: owner's problem → what we do → AED price or proof → CTA. Mention WhatsApp where natural ("or WhatsApp us"). |
| "In plain English" block | 60–90 words under the hero: what it is, who it's for in the UAE, AED price, timeline, "based in Dubai, we reply on WhatsApp". This is what Google AI Overviews and ChatGPT quote. |
| Prices | In AED as HTML text, "+5% VAT", with Offer schema (priceCurrency AED). |
| UAE specifics in copy | Name local tools and realities: Tabby/Tamara, Talabat/Deliveroo/Careem/Noon, Foodics, Fresha, Zoho Books/Odoo, Emirates ID login (UAE Pass), Arabic RTL, DED/free-zone licences, e-invoicing 2027. These are what make pages relevant to UAE searches and impossible to copy from a US template. |
| Mockups | `data-nosnippet` on every mockup container; short `aria-label`. UAE versions: AED, WhatsApp, Dubai areas (JLT, Al Quoz, Marina, Deira), +971 numbers. |
| FAQ | 6–8 questions in UAE phrasing ("Do you work with free-zone companies?", "Can the site be in Arabic and English?", "Do you accept payment in AED?"). FAQPage schema. |
| CTA | "Book a call" + **"WhatsApp us"** (`https://wa.me/971…?text=…` with a page-specific prefilled message). |
| Trust line | "Licensed in Dubai · Licence no. … · Replies on WhatsApp within 1 hour, Sun–Fri" (only once true). |
| Body length | ≥1,200 words of real text on service pages; FAQ + plain-English block + section copy usually gets there. |

### H2 pattern (keep the voice, add the topic)

| Section | Pattern |
|---|---|
| 2 Sound familiar? | "Sound familiar? Why Dubai owners call us about **[topic]**" |
| 3 Showcase | "**[Stores/Apps/Automations]** we build for UAE restaurants, salons and shops" |

### `/about`, `/contact`
- **About:** team with real names, photos and LinkedIn; Dubai base (free-zone licence number, address); working hours (Sun–Fri or Mon–Fri, GST/UTC+4); languages spoken (English, Arabic, Urdu/Hindi if true; it helps with many UAE owners). Title: `About [Brand] · A Software Studio Based in Dubai`.
- **Contact:** booking widget, WhatsApp, +971 number, email, map (only with a real address), reply time.

### Guides
- **Title:** the question, with "UAE"/"Dubai" where people search that way ("How Much Does a Website Cost in Dubai? 2026 AED Prices").
- **Structure:** answer first (2–3 sentences) → AED table → the owner's situation → detail → "What we'd do" + link → FAQ → author box.
- **Schema:** Article (author Person), BreadcrumbList, FAQPage.
