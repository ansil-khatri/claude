# 09 · Blog calendar: every guide with its title and content plan

Written 2026-10-09. This is the editorial plan for `/guides` on the UAE site: **55 guides + 3 data studies**, each with the H1 title, SEO title, URL, keywords, the opening moment, the outline, the facts it must include, internal links and the CTA. Writing rules are in `05-content-plan.md` §1 (answer first, UAE facts, honest, plain English, named author). Keyword bands come from `02-keyword-research.md`.

## How to use this file

1. Take the next guide in the calendar. Before writing, run the 4-step validation in `02` §O (Keyword Planner UAE, live search, People-also-ask, 3 real threads).
2. Write to the outline. Every H2 can be reworded to match the exact "People also ask" question you find.
3. **Facts marked ⚠ must be checked against the official source on the day you publish**, with the source linked in the article (laws, dates, fees and prices change).
4. Build the visuals listed (same mockup style as the site: real-looking screens, AED, WhatsApp).
5. Add the guide to its hub page's "Guides" block and link to it from 1–2 older guides (`03` §6).
6. Arabic versions (AR) are rewritten by the Arabic writer, not translated.

**Template for every guide:** answer box (2–3 sentences) → AED table or checklist → the owner's story → the H2s → "What we'd do" (2–3 lines + link) → FAQ (3–5) → author box. Cost guides 2,500–3,500 words, problem guides 1,200–1,800, comparisons 1,800–2,500.
