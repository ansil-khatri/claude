# New UAE Pages — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build mockups (and their specs) for every page the UAE site needs but doesn't have yet: hubs, pricing, about, process, contact, guides, the e-invoicing service, four calculators, 404/legal, seven solution pages, work/case studies, Abu Dhabi pages and an Arabic homepage prototype.

**Architecture:** Each new page is a single-file HTML mockup in `docs/superpowers/mockups/`, copied from an already-localized page of the closest type (homepage shell, service template or industry template) so it inherits the shared CSS, `SITES`, nav, footer and motion. Calculator maths lives in one tested library (`tools/lib/calcs.js`) and is pasted into each tool page inside a marker block so `sync.js propagate` keeps copies identical. Every page must pass the same toolkit as the localization plan (`uae-audit.js`, `verify.js`, `text-audit.js`).

**Tech Stack:** Static HTML/CSS/JS mockups with GSAP; Node 22 `node:test`; `playwright-core` + installed Chrome (toolkit from `2026-10-09-uae-localization.md` Task 1).

**Spec:** `docs/superpowers/specs/2026-10-09-new-pages-design.md` (pages N1–N18). Also binding: `docs/superpowers/specs/2026-10-09-uae-localization-design.md` (§4 brands, §5 prices, §6 components, §6.9 visual checklist). Copy for guides: `docs/seo-uae/09-blog-calendar.md`. SEO titles: `docs/seo-uae/04-on-page-seo.md`.

**Prerequisite:** the localization plan `2026-10-09-uae-localization.md` is complete (all 19 audits PASS). Don't start Task 2 before that.

## Global Constraints

- Everything in the localization plan's Global Constraints applies (AED format, VAT line, homepage prices, brand facts, WhatsApp, kg/km/°C, GST, one `<h1>` with `.h1-kicker`, `uae-shared` CSS only, Arabic in `dir="rtl"`, checked Unsplash IDs only, no git → `sync.js snapshot` backups).
- Page CSS prefixes (collision-checked 2026-10-09): `sv-` services hub · `ix-` industries hub · `pz-` pricing · `ab-` about · `pw-` process · `ct-` contact · `gd-` guides · `ei-` e-invoicing · `tc-` delivery calculator · `gf-` gateway fees (`pf-` is taken) · `rc-` readiness check · `so-` solution pages · `ac-` app cost · `wk-` work · `ad-` Abu Dhabi. Any other new class is grepped across all mockups first.
- Every new page passes: `node uae-audit.js <page>` → `PASS`; `node verify.js <page> ../_shots/<page>` → `OK` with every mockup ticked against the UAE spec §6.9; `node text-audit.js <page>` → `PASS`.
- Every new page gets its own spec `docs/superpowers/specs/<date>-page-<slug>-design.md` in the existing format (sections, copy, mockups, FAQ, "Consistency with homepage (AED)", open items) and is linked from `2026-10-09-new-pages-design.md`.
- Facts with ⚠ in the spec (e-invoicing dates and scope, gateway fees, Tabby/Tamara terms) are shown with a "checked on [date]" note and a source link on the page.
- No fake people: team members, client logos and quotes are placeholders until the owner provides real ones; concept examples carry `.ex-chip`.

```js
'use strict';
// Calculator maths for the /tools pages. Same functions are pasted into each tool mockup
// inside /* ===== calcs (shared) ===== */ so sync.js keeps them identical.
// Rates are illustrative, taken from public 2026 pages; each tool page shows "checked on [date]".

const num = v => (Number.isFinite(+v) && +v > 0 ? +v : 0);
const aed = n => 'AED ' + Math.max(0, Math.round(num(n))).toLocaleString('en-US');

function deliveryCommission({ ordersPerMonth, avgOrder, commissionPct, promoPerMonth, directSharePct, cardFeePct = 2.9 } = {}) {
  const appSalesYear = num(ordersPerMonth) * num(avgOrder) * 12;
  const commissionYear = appSalesYear * num(commissionPct) / 100 + num(promoPerMonth) * 12;
  const moved = appSalesYear * Math.min(num(directSharePct), 100) / 100;
  const keptYear = Math.max(0, moved * (num(commissionPct) - num(cardFeePct)) / 100);
  return { appSalesYear, commissionYear, keptYear };
}

const GATEWAYS = [
  { name: 'Stripe', pct: 2.9, fixed: 1, intlPct: 1, monthly: 0, note: '+1% international cards' },
  { name: 'Telr (Medium plan)', pct: 2.49, fixed: 0.5, intlPct: 0, monthly: 99, note: 'International surcharge: ask Telr' },
  { name: 'Ziina', pct: 2.6, fixed: 1, intlPct: 1.5, monthly: 0, note: '+1.5% non-AED / international' },
  { name: 'PayTabs', pct: 2.85, fixed: 1, intlPct: 0, monthly: 0, note: 'International surcharge: ask PayTabs' },
];

function gatewayFees({ sales, payments, intlSharePct } = {}) {
  const s = num(sales), p = num(payments), intl = s * Math.min(num(intlSharePct), 100) / 100;
  return GATEWAYS.map(g => {
    const monthly = s * g.pct / 100 + p * g.fixed + intl * g.intlPct / 100 + g.monthly;
    return { name: g.name, monthly, yearly: monthly * 12, note: g.note };
  }).sort((a, b) => a.monthly - b.monthly);
}

function einvoiceDeadline(band) {
  return band === '50m+'
    ? { asp: '30 October 2026', live: '1 January 2027' }
    : { asp: '31 March 2027', live: '1 July 2027' };
}

const READINESS = [
  ['aspChosen', v => (v === 'yes' ? 20 : 0), 'Choose your Accredited Service Provider (ASP)'],
  ['softwareReady', v => (v === 'yes' ? 20 : v === 'unsure' ? 5 : 0), 'Confirm your accounting software can send e-invoices'],
  ['trnsComplete', v => (v === 'all' ? 20 : v === 'most' ? 10 : 0), 'Add missing customer TRNs and addresses'],
  ['sources', v => (v === 'one' ? 15 : v === 'two' ? 5 : 0), 'Connect every place invoices are created (POS, Excel, other systems)'],
  ['owner', v => (v === 'yes' ? 15 : 0), 'Name one person responsible for e-invoicing'],
  ['tested', v => (v === 'yes' ? 10 : 0), 'Send test invoices through your ASP'],
];

function readinessScore(answers = {}) {
  let score = 0;
  const todo = [];
  for (const [key, points, task] of READINESS) {
    const p = points(answers[key]);
    score += p;
    if (p < points(key === 'trnsComplete' ? 'all' : key === 'sources' ? 'one' : 'yes')) todo.push(task);
  }
  return { score, todo };
}

const APP_BASE = { booking: 35000, ordering: 45000, delivery: 60000, loyalty: 35000, marketplace: 105000, internal: 29000 };
const APP_FEATURES = { payments: 6000, tabby: 3000, tracking: 12000, chat: 8000, admin: 10000, arabic: 5000, integrations: 9000 };

function appCost({ type, platforms, features = [], design } = {}) {
  const base = APP_BASE[type] || APP_BASE.booking;
  const extra = features.reduce((sum, f) => sum + (APP_FEATURES[f] || 0), 0);
  let low = (base + extra) * (platforms === 'one' ? 0.85 : 1) * (design === 'custom' ? 1.15 : 1);
  low = Math.round(low / 1000) * 1000;
  const high = Math.round((low * 1.6) / 1000) * 1000;
  const weeks = 6 + Math.ceil(features.length * 1.5) + (design === 'custom' ? 2 : 0);
  return { low, high, weeks };
}

module.exports = { aed, deliveryCommission, GATEWAYS, gatewayFees, einvoiceDeadline, readinessScore, appCost };
```

```js
#!/usr/bin/env node
'use strict';
// Lists mockups that no other mockup links to (relative href="<file>.html").
const fs = require('fs');
const path = require('path');
const dir = path.resolve(__dirname, '../mockups');
const pages = fs.readdirSync(dir).filter(f => f.endsWith('.html'));
const linked = new Set();
for (const p of pages) {
  const src = fs.readFileSync(path.join(dir, p), 'utf8');
  for (const m of src.matchAll(/href="([a-z0-9-]+\.html)/g)) if (m[1] !== p) linked.add(m[1]);
}
const orphans = pages.filter(p => p !== 'homepage.html' && !linked.has(p));
console.log(orphans.length ? 'ORPHANS:\n' + orphans.join('\n') : 'No orphans');
process.exit(orphans.length ? 1 : 0);
```
